# Developer News Strip — Design

Mockups for the developer news strip on the Creatio login page. Spec: [`docs/features/developer-news.md`](../../features/developer-news.md).

| File | Content |
|---|---|
| `mockup.html` | v1 interactive mockup: the strip under the profile row, expanded panel, four states (unread, all read, critical, no feed) |

Open `mockup.html` directly in a browser; no build step. Click the strip to expand it and use the Scenario switch on the right. News texts in the mockup are placeholders.

When iterating, keep the previous version (`mockup-v1.html`, `mockup-v2.html`, …) if the change is substantial, so variants can be compared.
