    Escalation ladder

    Each level is used only if the one before is not enough. Normal news never go above level 2.

    level 0 · nothing new

    No change

    The button looks exactly as today.

    level 1 · ambient

    Dot on the button

    8 px orange dot with a ring, no number. Clears as soon as the menu is opened. Decays after 7 days or 10 Shell loads even if ignored.

    level 2 · in context

    What's new row

    First row of the menu, two lines: count + newest headline. Click opens the flyout next to the menu; that marks items read.

    level 3 · critical only

    Peek card

    Once per critical item across both surfaces, max one per day. Auto-hides after 10 s, pauses on hover, never steals focus.
